# ALTPro-Labs Wallpaper Content Repository

## Purpose

This repository contains the original wallpaper content and metadata used by
ALTPro-Labs wallpaper applications.

The Android application source code is maintained separately.

This repository must never contain:

- Android application source code
- application signing keys
- API credentials
- access tokens
- private encryption keys
- user information
- analytics credentials
- secrets of any kind
